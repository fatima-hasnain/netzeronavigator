# Net Zero Navigator

In-browser explorer for EnergyPlus surrogate models: load a static TensorFlow.js bundle, move inputs, and read end uses plus derived TEDI / CEDI / EUI / GHGI / cost.

```bash
npm install
npm run dev
```

Open http://localhost:5173 — Home → sample surrogate, or `/s/20200224`.
